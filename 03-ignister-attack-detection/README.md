K# 03-Ignister Attack Detection Engine

A multi-attribute threat classification and telemetry correlation engine inspired by the **Yu-Gi-Oh! @Ignister** Cyberse archetype. This tool ingests raw telemetry streams generated by simulation modules, evaluates events against detection rule profiles, categorizes threats across six core elemental attack vectors, and exports structured JSON incident reports.

## 🛠️ Cyberse Attribute Detection Rules

| Attribute | Incident Category | Simulation Trigger |
| :--- | :--- | :--- |
| **DARK** | Credential / Auth Abuse | SSH brute-force & login failures |
| **FIRE** | High-Volume Exfiltration | Massive outbound byte transfer stream |
| **WATER** | Application Injection | SQLi (`' OR 1=1 --`) payload execution |
| **EARTH** | Reconnaissance / Probing | Nmap SYN port scanning across host ports |
| **WIND** | DDoS / Session Flood | High-frequency packet bursts (5000 pkts/sec) |
| **LIGHT** | C2 Execution / Dropper | Reverse shell execution (`reverse_shell.elf`) |
